## 1. 重大技术发现：sim.step() 步长 = 0.02s（非 0.005s）

本环境 IsaacLab 配置为 **打包步进**：一次 `sim.step()` 前进 0.02s，内部由 PhysX 完成 4×0.005 子步积分；
公开 API 无法按 0.005 粒度采样。

**三重实测验证**（toss 定标 + 数据内审）：
- 竖直上抛定标：N=16 步 / 理论飞行 0.3058s → 步长 ≈0.019~0.02s
- 抛物线 g 拟合 = **9.81**（理论 9.81，误差 <0.1%）
- 自由落体 g 拟合 = **9.81**；水平动量守恒 0.500 / 设定 0.500（<0.5%）

**连带修正**：P1 交付数据首版时间戳误标 dt=0.005，已重采为 v2（t=k×0.02，50Hz 步末瞬时值，
时长精确 2s/4s；超调等时不变指标与首版一致，时域指标 4× 修正）。P0 不受影响（控制步采样本就正确）。

## 3. 参考事实（Isaac 侧行为基线）

1. **积分精度模范**：g 双实验 9.81、水平动量守恒 0.5% 内——Isaac 的对标数据本身过物理审计。
2. **原生 PD 静站 ~0.5s 必塌**：解锁后前 0.5s 双脚 Fz 合计 372N≈体重 343N（站立成立），
   0.5-1s 衰减至 185N，1s 后趴地（z→0.076）。与 P0 的"PD 在病理片段摔倒"互证：
   **Isaac 原生 PD + 默认增益不具备静态自稳能力**——MuJoCo 侧同协议预期同样塌，塌的速率与
   力衰减曲线即 V6 对比对象。
3. **刚性接触低回弹**：0.3m 落体（锁关节直立）冲击力峰 2467N（≈7×体重），一次弹跳峰高
   ≈0.017m（恢复系数 ~0.13 量级）后进入衰减序列。
4. **质量读数**：articulation API 未取到总质量（0.0kg），以静立 Fz≈343N 为体重锚点。
