## 过程中踩的三个坑（后续换机注意）

1. **云实例中途重置**：12:29 有 crash 重启记录，恢复好的 /root/GR00T-WholeBodyControl
   曾被清掉（其余归档幸存）。→ 已重传并另存 GR00T_quick_backup.tgz。
   换机建议：铺完立即打快照包。
2. **macOS tar AppleDouble 污染**：从 Mac 打包 env 传入 15.8 万个 `._*` 资源叉垃圾文件，
   Kit 启动时报 `invalid ELF header` / `UnicodeDecodeError`。
   → `find /opt/Anaconda3/envs/isaac \( -name "._*" -o -name ".DS_Store" \) -delete`。
   换机建议：Mac 打包用 `COPYFILE_DISABLE=1 tar` 或改用 rsync 直传目录。
3. **urdf importer 版本不匹配**：备份（8/18 19:25）的 env 里
   isaacsim.asset.importer.urdf 2.4.19 的 `_urdf.ImportConfig` 无
   `set_merge_fixed_ignore_inertia`，而 IsaacLab v2.3.2 调用它——说明备份之后、
   round-2/3 运行之前 555 上该组件被更新过，备份存的是旧版。
   → patch `/root/IsaacLab/source/isaaclab/isaaclab/sim/converters/urdf_converter.py`
   第 143 行为 `hasattr` 守卫（原文件备份 .bak）。该方法只设置默认值 False，
   跳过调用语义等价；P1 验证通过证实无副作用。
