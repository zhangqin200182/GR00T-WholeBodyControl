# Isaac–MuJoCo 仿真精度对齐报告（v18 模型，2026-08-27）

> 任务：把 MuJoCo 侧 G1 模型对齐到 Isaac 官方环境的实测接触行为。
> Isaac 侧真值来自本项目 R5/R6 六轮采集与探针（双引擎对照已定量落定）。

## 1. 对齐依据（Isaac 侧实测真值）

| 项 | Isaac 实测 | 来源 |
|---|---|---|
| 脚部碰撞几何 | 每脚 **7 capsule**（5 杆 r=0.008/0.01 L=0.167-0.186 + 2 踝销 r=0.01 L=0.05），相对 ankle_roll 原 y 轴向布置，sole 在原点下方 33-35mm | URDF 权威数据（R2 specs A1）|
| 接触生成阈值 | pair contactOffset 合成 ≈ **4.3-6mm**（受载站距 4.3-4.5mm 机制闭环；restOffset=0）| R6/R6b 官方 env pinned 深档 |
| 生成阈值处力 | 分离 +4.0~+6.3mm 处 **118-156 N/脚**（= Isaaac -20/-25mm 档实测）| R6b sole-sep 精算表 |
| 零穿透支撑力 | 站立 ≈ 体重 441N（双脚 ~220N/脚）| 官方 env 物理事实 |
| 脚摩擦 | 官方 env 随机化 static [0.3,1.6]（p50≈0.95），combine=multiply | R6b events 实锤 |
| 深穿透区 | 力平坦 ~150-250N/脚不随深度（TGS 特性；MuJoCo 为软弹簧增长——引擎本质差异，浅区对齐优先）| 同事 probe41 + Isaac 深档 |

## 2. v17 现状（对齐前）

- 脚 = **单个 box**（16×7×3cm），margin=0（触地即全力，无 4.4mm 生成带）
- friction 0.9、solref="0.04 0.8"、solimp="0.8 0.95 0.005 0.5 2"

## 3. v18 对齐改动（g1_29dof_v18_isaac_aligned.xml）

1. **几何**：两脚 box → 各 7 capsule（URDF 原值；Isaac PhysX halfHeight = L/2 − r
   换算为 MuJoCo fromto 端点 x ± (L/2 − r)，r 同）——14 个 capsule 与 Isaac 运行时逐一同款
2. **margin="0.0044" gap="0"**：对齐 Isaac 接触生成阈值（4.4mm = R6b 实测带中心/同事机制推断值）
3. friction/solref/solimp 沿用 v17 值（0.9 在 Isaac 随机化带内；solref 浅区行为见下验证）
4. 驱动不在 XML（MuJoCoEnv 代码层设置，与 Isaac 同 CFG 公式——D1 已证）

## 4. 验证（本地 MuJoCo settle 探针，同 R6 协议：root pin 档位 + 锁关节）

`settle_probe_mj.py`（随提交），v18 实测 vs Isaac：

| sole 分离 | MuJoCo v18 力（双脚）| Isaac 对照 |
|---|---|---|
| +6mm（margin 外）| **0 N**（ncon=0）| 无接触 ✓ |
| **+4mm（margin 内）** | **238 N（≈119 N/脚）** | **Isaac 同分离 118-156 N/脚——精确同量级** ✓ |
| +2mm | 363 N | 缓升区 |
| 0mm | **449 N ≈ 体重 441N** | 零穿透支撑=体重 ✓ |
| -6mm | 690 N | 软弹簧增长（MuJoCo 特性）|
| -25mm | 1476 N | Isaac 深区平坦（引擎本质差异，见 §5）|

**结论：接触生成距离（4.4mm）、生成带内力量级（~120N/脚）、零穿透支撑（体重）
三个锚点全部对齐。**

## 5. 残余差异（声明，非 bug）

- **深穿透区**：Isaac TGS 深区力平坦（~150-250N/脚），MuJoCo solref 软弹簧随深度增长。
  正常训练工况为浅区（0-5mm），已对齐；深区仅在跌倒等异常出现。如需进一步拟合，
  可迭代 solimp（width/dmax 限幅）——建议有 Isaac 干净深区曲线（平衡起点协议）后再调。
- v17 box 基线的探针对照未完成（box 模型 q0 姿态适配问题），几何差异已由
  URDF 数据直接说明，不影响 v18 结论。
