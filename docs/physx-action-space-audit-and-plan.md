## 一、同事实验审计（GR00T-npu-experiments）

### 1.1 实验概况

同事（Maxwell-AI-lab）基于我们的 MuJoCo 线做了"NPU + CPU 物理微调 SONIC"全链路实验：

| 项目 | 内容 |
|------|------|
| 起点 | 官方 Isaac 训练的 SONIC 37M 权重（step 41550）|
| 核心修复 | E3：逐关节移植 Isaac 精确动作空间（act_scale/kp/kd/effort）|
| 训练 | 两轮微调：5000 iter → 11000 iter（1024 envs × 128 workers）|
| 数据 | 仅 2 条步行片段（80 秒）|
| 结果 | 速度贴合参考（0.73 vs 0.72 m/s），长度 1476 步 |
| 交叉验证 | 官方权重进 MuJoCo：7 步摔；微调权重回 Isaac：**8 步摔**（E9 对称性实验）|

### 1.2 关键发现：训练用的物理是我们已证伪的针尖模型

同事的 `train_agent_trl.py` 有一处关键改动：**`g1_29dof_v17.xml → g1_29dof.xml`**，把我们的 P0/P1/P1.5 物理修复全部回退：

| 项目 | 我们的 v17 XML（P0 修复后）| 同事用的 g1_29dof.xml |
|------|---------------------------|----------------------|
| 脚接触 | 16×7cm box（solref/solimp）| **8×5mm 小球** |
| 单脚接触面积 | 112cm² | 3.14cm²（1:36）|
| 关节阻尼 | 29 joints damping | 0 |
| frictionloss | 有 | 0 |

这正是我们 v12-v15 诊断、v16-v18 三个版本修复的"在针尖上跳舞"模型（当时症状：length 2.0 地板、PD 9.2 步死）。

### 1.3 本地实证复现（Mac，零 NPU 依赖）

**复现 1：训练结果属实**。本地用同事的 env + checkpoint 实跑：
- 1926 步 / 21.65m / 速度 0.56 vs 参考 0.44 m/s / 骨盆高稳定 0.77-0.79
- 他们的声称（984-1616 步、速度贴合）全部复现——训练过程与评测是诚实可信的

**复现 2：纯 ref PD 对照（决定性）**：

| 指标 | 纯 ref PD（参考动作照抄）| 同事策略 |
|------|------------------------|---------|
| 脚埋入深度 | **-24mm**（几乎全埋）| **2-3mm**（受控浅触）|
| 接触力 | 病态：85% 负法向力，范围 [-82,+13]N | 受控振荡 ±20N |
| 结论 | 参考动作在该物理上**不可执行** | 学会了在软接触上的精准浅触平衡 |

**复现 3：步态机制**。力迹线分析显示：双脚**始终**接触地面（无支撑/摆动交替），接触力正负振荡（软接触求解器病态的签名），踝关节缓慢摇摆驱动交替推地——**这是"搓行"，不是足部滚动的真步行**。之前"94% 单支撑"的统计是振荡力穿越阈值的假象。

### 1.4 判定：三问三答

| 问题 | 判定 | 证据 |
|------|------|------|
| 训练是否真实？| ✅ 真实 | 本地复现通过；健康曲线；诚实评测纪律（自己抓出录制 hack 失真）|
| 方法是否正确？| ✅ 大体正确 | E3 动作空间对齐是真贡献；对照组思维；奖励塑形链（掉队判死+r1×4）有方法论价值 |
| 是否过拟合不成熟仿真？| ✅ **是** | ①训练物理=已证伪的针尖模型 ②Isaac 回传 8 步摔（他们自己的 E9）③2 片段 80 秒数据，速度贴合是拟合非泛化 ④策略技能=软接触浅穿透搓行，该机制在 Isaac 真实鞋底接触中不存在 |

**核心机制**：策略学会了"不信参考的脚，只信参考的骨盆"——跟踪参考的骨盆轨迹（位置奖励+掉队判死逼的），同时发明针尖特化的脚部动作（搓行）。这是 RL 的补偿能力，但补偿建立在仿真缺陷上，不可迁移。

## 二、关键概念澄清（审计过程中的共识）

### 2.1 动作不是力矩，是归一化关节目标位置

```
策略网络 → action ∈ [-1,1]（归一化位置目标）
   ↓ 动作空间翻译（Isaac: default + 0.25·e/k·a；我们: jm + jh·a）
目标关节位置 → PD 控制器（kp/kd）→ 力矩 → 物理
```

训练样本的 action 字段 = 归一化位置；力矩只在 env/驱动内部出现；BC loss 也是位置空间（MSE(model action, ref_action)）。

### 2.2 纯 ref PD 是什么、为什么是参考标准

- **纯 ref PD** = 每帧照抄参考动作喂给 PD 执行，策略零参与（我们的评测脚本 `--trust 0.0`）
- 参考动作来自数据集（PKL 动捕序列），PD 是代码里的固定增益控制器——数据带"去哪里"，PD 负责"怎么执行"
- **它是零学习基线（下界）**：训练策略必须在同条件下（同种子/同阈值/确定性）有意义地优于它，否则训练减分了
- 四种组合的诊断：都摔=物理/参考不可行；PD 活策略摔=训练坏了；**PD 摔策略活=学会了补偿（需警惕补偿性质）**；都活=比边际
- 注意：PD 基线是动作空间的函数（同事 E3：同一参考，旧空间 4 步摔→新空间零摔倒）——换动作空间必须重测 PD 基线

### 2.3 "过拟合"的精确机制

过拟合 ≠ "适应了训练环境"（所有 RL 都如此），而是 **"适应的技能依赖训练环境的特殊缺陷"**：

| | 同事针尖模型 | 我们修复后物理 |
|---|---|---|
| 参考动作可行性 | 完全不可行（埋脚 24mm）| 部分可行（31 步）|
| 策略学的补偿 | 绕过不可行（搓行偏方）| 把部分可行变稳定可行 |
| 技能机制 | 软接触缺陷特化 | 真实物理机制（平衡/踩地/管高度）|
| 迁移资格 | 无（Isaac 8 步摔实证）| 有机会（未验证）|

判断标准：**在"参考能走起来"的物理里学的补偿是可迁移的执行技能；在"参考完全走不了"的物理里学的补偿是不可迁移的偏方。**

### 2.4 官方权重为什么没解决"动捕 gap"

官方权重确实学会了补偿动捕-机器人 gap（在 Isaac 里），但补偿是以 **Isaac 动作空间语义编码**的（输出 1.0 = 推 0.35 rad）。我们的 env 用半行程缩放（1.0 = 推 2.71 rad）——**7.7× 语义错配**，同样的输出变过冲，补偿全部失真。同事的 E2 是实锤：官方权重进旧空间 MuJoCo 每 4 步摔。

## 三、我们 PhysX 线的动作空间诊断

### 3.1 三种动作空间对比

| 环节 | Isaac 官方（权重出生地）| 同事 E3（MuJoCo）| **我们 PhysX（现状）** |
|------|----------------------|-----------------|----------------------|
| 动作→目标 | default + 0.25·e/k·a | 同 Isaac ✅ | **jm + jh·a（半行程）** |
| 腿关节 a=1 位移 | ≈0.35 rad | ≈0.35 rad | **2.71 rad（7.7×）** |
| 刚度 kp | armature·ωn² ≈ 99 N·m/rad | ≈99 ✅ | **99×15000=1.5e6（补偿）** |
| 阻尼 kd | 2ζ·armature·ωn ≈ 6.3 | ≈6.3 ✅ | 基数×缩放+手扫 ζ |
| 力矩限幅 | 139/88/50/25/5 逐组 | 同 Isaac ✅ | 统一 50 |

### 3.2 错配的三层后果

1. **网络技能单位错乱**：release 权重学的是"输出 1.0 = 推 0.35 rad"，我们 env 变成 2.71 rad——所有精细修正模式 7.7× 过冲，官方经验无法落地
2. **kp×15000 是错误标度上的暴力补偿**：`physx_loader.py` 注释自认——Isaac 的 omni 包装做了惯性归一化，我们的 Direct API 没有，于是用扫描（`sweep_accel_kp.py`）暴力放大；kd 的 ζ 也要分组手扫——正常物理不该需要这种量级
3. **策略行为病理**：踝泵动/抖动（Phase C 振荡回退）与过敏感动作空间互为因果

### 3.3 与同事实验的因果证据

同一权重、同一引擎、只换动作空间三件套：**每 4 步摔 → 零摔倒**。动作空间对齐是官方技能可迁移的必要条件——单变量实验，无混淆。

## 四、修复方案：E3 动作空间移植（A/B 实验）

### 4.1 改动清单（3 个文件，本地开发）

| 文件 | 改动 |
|------|------|
| `gear_sonic/envs/physx_env.py` | `_pd_control`: `target = act_offset + act_scale × action`（逐关节 Isaac 公式）；`_obs`: `ref_action = (ref_qpos − act_offset)/act_scale`（BC loss 目标同步换空间）|
| `gear_sonic/envs/physx/physx_loader.py` | kp/kd 回 Isaac 基数（撤 ×15000/ζ 手扫，保留 A/B 开关）；力矩限幅改逐关节 effort（139/88/50/25/5）|
| 评测脚本 | 无需改（env 内部处理）|

### 4.2 验证路径（便宜且决定性）

1. **官方 release 权重零样本**新旧空间对比——预期新空间能站稳/走一段（MuJoCo 同事实测：4 步摔→零摔倒）
2. **ref PD 基线重测**——新空间下 PD 应该提升（参考动作被"冤枉"的程度降低）
3. 若新空间官方权重 ≥100 步 → 切换主线；若无差别 → 保留旧线

### 4.3 预期收益与风险

- 收益：去掉暴力刚度补偿；官方权重 gap 补偿白捡；BC 起点质变；迁移前景
- 风险：旧 checkpoint 作废（动作空间不兼容），需重标定
- 对冲：A/B 实验零训练成本，先做实验后决策

## 五、调整后的训练计划

### 5.1 资产盘点

**永久保留**：物理层修复全部（P0 帧/脚接触/自碰撞/offset=0.04）、管线修复（checkpoint 键/fail-fast/掩码/配置去泄漏）、方法论（宽松训练+严格评测/trust 阶梯/死亡诊断→塑形套路/踝速度惩罚）、SDK 构建配方、评测渲染管线。

**可能作废**（仅当切换）：旧动作空间 checkpoint（BC-300/t05/PPO 1300/1600）、62.3/58.2/32.9 降级为对照基线、hinge 具体数值需重新验证（方法论保留）。

### 5.2 阶段计划

| 阶段 | 内容 | 判据 |
|------|------|------|
| **收尾** | vel-penalty 1600 评测 | 旧空间最终基线（对照基准）|
| **Phase A** | E3 移植 A/B（本地开发）| 官方权重零样本新旧对比 + ref PD 重测 |
| **Phase B** | 决策 | 零样本 ≥100 步 → 切换主线；否则保留旧线 |
| **Phase C** | 对齐空间重标定 | 轻 BC/微调（官方权重起步）→ PPO（沿用配方，hinge/踝塑形重新验证，踝速度惩罚保留）|
| **Phase D** | 迁移验证（必修课）| **Isaac 回传**（复用同事云 GPU 环境）+ 跨片段评测（12 条动捕全量/留出集）+ 渲染人检 |

### 5.3 教训沉淀

1. 训练前先验物理：ref PD 可行性是第一道关（PD 摔要看怎么摔——病态死因暴露物理缺陷）
2. 动作空间对齐是官方权重迁移的必要条件
3. "过拟合"判定的两个硬标准：Isaac 回传 + 跨数据评测（不能只看训练分布上的数字）
4. 超越 PD ≠ 有效：要看超越的方式（精确跟踪+微补偿 = 健康；发明新步态绕过不可行 = 病态）
