# Isaac 侧采集请求 Round-3：free-root + 植定脚承重 stance 响应

> 2026-08-20。前两轮采集的推进已把植物分歧收敛到唯一未测区间：**free-root + 承重 + CFG 忠实软增益 + 耦合链**。此前一切实验要么无载（P1 root-fix）、要么硬增益（mult=10）、要么单关节——本区间恰是 release 策略的工作点。

## 背景（一分钟）

我们的植物在 replay 中与你们的分歧链：接触瞬态 ✅ 健康、静立锚定 ✅ 健康（CoP 模式两引擎同款）→ 分歧 = 近端链（髋/膝）承重下的 stance 相位偏差（0.1-0.26 rad）。髋/膝 load-deflection 用现有数据判不动（我们侧 readback 被接触反力主导，隔离不了驱动输出）。**需要你们录制同协议的承重 stance 响应**，拿到你们的 applied_torque（=驱动输出，你们的字段语义）作为驱动-载荷耦合的对照。

## 采集协议（P1 协议改两点）

沿用你们的 P1 驱动响应协议（27 组：3 关节 × 阶跃 ±0.05/0.1/0.2 × 正弦 0.5/2/5Hz，200Hz 记录，dt=0.02 控制步），改动：

1. **free-root**：不锁 root、不 fix——机器人站立姿态、双脚植定地面（初始 5mm 微穿透即可，保证接触约束活跃）
2. **关节范围**：hip_pitch / hip_roll / knee × L/R 任意一侧（踝已知健康不用测）+ 每次单关节扰动（其余关节 PD 持姿）

其余不变：CFG 原始增益（kp=armature·ω², ω=2π·10Hz, ζ=2.0——你们的默认驱动配置，勿用任何 stiff 变体）、阶跃/正弦幅度、200Hz 记录、applied_torque/qpos/qvel/target 字段、根漂移记录（root_drift_max 已有字段保留）。

## 预期判读

- 我们同协议重跑：同扰动、同增益、同承重 → 对比 q 响应（rise90/幅值/相位）与 applied_torque 波形
- 响应一致 → 近端承重无分歧 → E8 放行（config 侧并行启动）
- 响应分歧 → 分歧在 free-root 承重耦合（根动力学/接触约束内的驱动传递）→ 先修再训
