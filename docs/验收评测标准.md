# 仿真环境与训练结果验收评测规范

**版本**：V2.1（通用规范）
**适用范围**：基于物理仿真的机器人策略训练——环境、训练过程、最终策略三类对象的可信度验收
**方法论依据**：VV&A（DoD 5000.102、RAND R4249）；RL 统计评估（rliable, NeurIPS 2021）；接触动力学验证（GRF 对比惯例）

三大对象的逻辑关系：**①是入口**（环境不可信则一切后续无意义）→ **②是护栏**（把失败发现从"终考"提前到训练中）→ **③是裁决**（对声明用途放行）。任何红灯都不删除产物，只停训归因，归因结论回注标准（R6）。

## 1. 术语

| 术语 | 定义 | 本项目实例 |
|---|---|---|
| 训练引擎 | 提供梯度来源的物理仿真 | MuJoCo（CPU） |
| 参照引擎 | 独立于训练引擎的物理仿真，用于普适性验证 | Isaac Sim（PhysX） |
| 权威资产 | 机器人定义的权威数据源 | 官方 URDF |
| 参考动作 | 用于跟踪训练的动捕/重定向动作片段 | motion PKL |
| GRF | 地面反作用力（Ground Reaction Force） | 脚-地接触力 |
| IQM | 四分位间均值：截去最低 25% 与最高 25% 后的均值 | — |
| IQR | 四分位距：P75 − P25 | — |
| 回合 | 一次环境 reset 到终止的完整轨迹 | episode |

### 1.1 对照基准分类与执行环境

每项测试必须声明其**基准**（跟什么比）。基准分四类，类别即决定执行环境：

| 基准类型 | 比什么 | 测试项 | 执行节点 |
|---|---|---|---|
| **A 权威资产** | 仿真模型与 URDF/官方 MJCF 逐项规格 | V1 | CPU（读文件比对） |
| **B 物理定律与公式** | 仿真输出与解析理论值：重力（必倒+坍塌时间尺度≈自由落体）、不可穿透（穿透=0）、能量守恒（残差=0）、抛物线公式 z=z₀+v₀t−½gt² | V2、V3、V7、V8 | CPU（MuJoCo 回放+公式计算） |
| **C 参照引擎（Isaac）** | 同一输入在两个引擎的输出：GRF 力曲线、策略存活步数 | V6、G3、T3 | **GPU**（Isaac 侧回放；MuJoCo 侧仍在 CPU） |
| **D 行为与历史基线** | 与参考动作、零样本锚点、历史运行、自身基准变体比 | V4（参考动作）、V5（零样本锚点）、G1（历史曲线）、G4（基准变体）、G5/T4（阈值与自身趋势）、T1（参考速度/回合上限）、T2（训练集自身） | CPU / 训练节点 |

**节点要求**（开训前就位并过连通性检查）：

| 节点 | 承担 | 要求 |
|---|---|---|
| 训练节点 | 策略训练；G1、G2 数据来源 | 满足训练框架要求；权重与日志可导出 |
| 评测节点（CPU） | 基准 A/B/D 全部测试 | 与训练节点**同版本**物理引擎与机器人模型（md5 一致）；评测脚本依赖与视频编码工具；磁盘 ≥20GB |
| 参照引擎节点（GPU） | 基准 C 全部测试（V6、G3、T3） | GPU 显存 ≥8GB；参照引擎可无头运行；接受最小策略权重（CPU、fp32、无训练框架依赖对象）；产物外传通道 |

**跨节点要求**：

- **权重传输**：跨引擎测试前导出最小策略文件（仅 `policy_state_dict`，CPU、fp32、剥离训练框架自定义类）；接收端加载结果计入 G3/T3 记录。
- **版本一致**：评测节点机器人模型与训练节点 md5 一致；参照引擎侧机器人模型与其权威资产一致（V1 适用于两侧）。
- **运维注意**：参照引擎评测进程异常退出后须确认显存已释放方可重跑；产物按时间戳取本次运行。
- **断点重跑**：GPU 节点不可用时仅阻塞基准 C 三项，其余测试与训练不受影响。

## 2. 总则（适用于全部测试）

**R1 用途绑定**：验收结论只对声明用途有效。开训前必须书面声明用途（模板：*在〈训练引擎〉中训练的策略，其技能须在〈目标环境〉中保持功能*）。

**R2 预注册**：评测点（迭代数/时机）、动作集、种子数在开训前声明并冻结；禁止事后挑选 checkpoint 或动作集。

**R3 评测语义一致**：评测管线与训练管线的动作语义（裁剪/缩放/延迟）、观测构成必须逐项一致；任何差异须显式声明并验证无影响。

**R4 统计纪律**：所有行为指标以分布报告，不以单次观测作结论。最低要求：每测试点 ≥20 回合（不同初始状态，起点均匀覆盖动作时长），报告 IQM、中位数、IQR；跨引擎测试 ≥5 次重复（不同随机种子），报告中位数与最小值。

**R5 环境指纹**：每次训练归档 XML/模型文件 md5、数据文件清单、全部命令行与配置、代码版本。环境任何改动须重新触发第 3 节环境验收。

**R6 阈值修订**：本规范阈值为 V2.1 默认值；修订须升版本号并记录依据（如实测数据、文献），历史版本保留。

## 3. 环境验收（Verification）

**时机**：任何环境创建或改动之后、开训之前。**全项通过方可开训。**

### V1 结构保真

- **目的**：仿真模型与权威资产一致。
- **基准**：A 权威资产（URDF 规格）。
- **方法**：程序化比对仿真模型与权威资产的逐项参数：碰撞几何（类型、尺寸、位姿）、质量、质心、惯量张量、关节限位、执行器力矩极限。
- **指标**：逐项相对误差。
- **通过线**：碰撞几何规格完全一致（类型与尺寸零偏差）；质量/惯量相对误差 <1%；限位与力矩极限零偏差。
- **记录**：比对脚本输出全文。

### V2 零力矩下落

- **目的**：排除"免费稳定"（接触或重力模型错误导致被动平衡）。
- **基准**：B 物理定律——重力与支撑。理论预期：无执行力矩则必倒；坍塌时间尺度与自由落体同量级（h 高度自由落体 t=√(2h/g)）。
- **方法**：机器人置于直立位姿，所有执行器力矩置零，仿真 ≥5s，记录骨盆高度时间序列（含关节阻尼值，若非零须声明）。
- **指标**：跌落量 Δh = h(0) − min(h)；跌破 0.45m（摔倒线）的时刻 t_fall。
- **通过线**：Δh > 0.3×站高；t_fall 与 √(2h₀/g) 在同一数量级（0.3–3 倍）。
- **记录**：高度时间序列（t, h(t) 逐点）。

### V3 穿透审计

- **目的**：验证不可穿透约束未被接触模型放水。
- **基准**：B 物理定律——物质不可穿透。理论穿透 = 0。
- **方法**：以固定策略（参考回放或固定 checkpoint）滚动 ≥600 控制步，采样全部脚-地接触的 `contact.dist`（负值为穿透）。
- **指标**：穿透深度分布（中位数、P95、P99、最大值）。
- **通过线**：中位 <0.5mm；P99 <5mm；单次最大 <15mm 且仅允许出现在冲击瞬态（触地后 ≤3 控制步内）。
- **记录**：分布统计与最差事件时间戳。

### V4 参考可行性（PD 回放）

- **目的**：参考动作在"简单控制器 + 本环境物理"下接近可行，排除环境对合理动作的惩罚。
- **基准**：D 行为基线——参考动作自身（无理论值，判据为经验下限）。
- **方法**：参考动作的关节角序列按环境自身伺服语义逐控制步作为目标（`a=(ref−offset)/scale`，不做裁剪），回放 ≥1000 控制步或至终止；对 ≥3 条不同参考动作各重复 ≥5 次（不同起始相位）。
- **指标**：存活步数分布（中位数、IQR）。
- **通过线**：中位数 ≥30 步，且每条动作 5 次中最差 ≥15 步。
- **记录**：逐动作分布表。

### V5 零样本基准（锚点记录）

- **目的**：为后续跨引擎对照建立零样本锚点。
- **基准**：D 历史基线（自身，不设通过线）。
- **方法**：参照引擎中训练的基线策略（若有）直接置于本环境，跑 ≥5 回合。
- **指标**：存活步数中位数。
- **通过线**：无（锚点记录；数值剧变提示环境语义漂移）。
- **记录**：数值 + 权重指纹。

### V6 接触保真（GRF 对比）

- **目的**：定量验证训练引擎与参照引擎的接触动力学一致性。
- **基准**：C 参照引擎——同输入下 Isaac 的 GRF 曲线。
- **方法**：同一初始状态 + 同一开环动作序列（≥200 控制步，含 ≥10 次触地事件）在两个引擎各回放一次；提取每次触地的竖直 GRF 曲线。
- **指标**：逐触地事件的峰值力相对误差、加载率（峰值/上升时间）相对误差、时序偏移（互相关滞后）。
- **通过线**：峰值误差中位 <15%；加载率误差中位 <20%；时序偏移中位 <20ms；无漏检/多检触地事件。
- **记录**：GRF 曲线叠加图 + 逐事件误差表。
- **执行环境**：Isaac 侧须 GPU；MuJoCo 侧 CPU。

### V7 能量守恒审计

- **目的**：验证能量账目平衡——系统不凭空储能/放能。
- **基准**：B 物理定律——能量守恒。理论残差 ε = 0。
- **方法**：回放固定动作序列（≥500 控制步，含 ≥10 次触地事件），逐控制步记录：系统机械能 E（动能+势能，含关节）、执行器做功 W（力矩×角位移累加）、接触耗散 D（接触力×接触点速度积分；引擎不提供时由能量差反推并声明）。
- **指标**：逐控制步能量残差 ε = ΔE −（W − D）；累计残差比 = |Σε| ÷ Σ|W|。
- **通过线**：累计残差比 <5%，且 Σε 无随时间单调增长趋势。
- **记录**：E、W、D、累计 ε 时间序列。

### V8 腾空抛物线检验

- **目的**：验证自由飞行段严格服从抛体运动。
- **基准**：B 物理公式——z(t) = z₀ + v₀t − ½gt²。
- **方法**：选取含明确腾空段的动作（跳跃类，连续腾空 ≥10 控制步），回放并标记双脚均无接触的时间窗；提取该窗口质心竖直位置序列，拟合二次曲线。
- **指标**：拟合残差 RMS；拟合重力加速度 ĝ 与标称值 g 的相对偏差。
- **通过线**：残差 RMS <5mm；|ĝ − g| ÷ g <2%。
- **记录**：质心轨迹与拟合抛物线叠加图、腾空窗口标记。

## 4. 训练过程门禁

**时机**：每 N 迭代（N 在预注册中声明，默认 2000）执行一次。

### G1 学习健康

- **目的**：确认环境/配置变更未显著拖慢学习。
- **基准**：D 历史基线——预注册的对照运行（同数据、已过验收环境）。
- **方法**：从训练日志（或 TensorBoard 事件文件）提取回合奖励标量，按门禁周期分段求均值，与对照基线逐段对比。
- **指标**：ρ = 本运行该段均值 ÷ 对照基线同迭代段均值。
- **绿灯**：ρ ≥ 0.5；**红灯（停训归因）**：ρ < 0.5 且连续两个评测窗。
- **记录**：分段对照表（段号、本运行、基线、ρ）。

### G2 进程健康

- **目的**：及早发现训练挂死或崩溃。
- **基准**：无（自身运行状态）。
- **方法**：读取训练日志 mtime 与最新迭代号，两次采样间隔 ≥ 门禁周期；检查主进程与 worker 进程存活数。
- **指标**：日志停滞时长 Δt；迭代增量 Δiter；存活进程数。
- **绿灯**：Δt < 10min 且 Δiter > 0；**红灯**：Δt ≥ 10min 或进程异常退出（记录尾部日志，不自动重启）。
- **记录**：采样时间戳、Δt、Δiter、尾部日志摘录。

### G3 跨引擎里程碑回传

- **目的**：检测引擎特化是否随训练加深。
- **基准**：C 参照引擎（Isaac 存活步数）+ D 历史回传值 min(h)。
- **方法**：取当前里程碑 checkpoint，导出最小策略权重（仅 `policy_state_dict`，CPU、fp32、无训练框架依赖对象）；置于参照引擎，以与训练侧完全相同的评测配置回放，≥5 个随机种子；同时记录训练侧同迭代任务指标。
- **指标**：参照引擎存活步数中位数 m；对照量：零样本锚点 b（V5）、历史各次已训回传最低值 min(h)。
- **绿灯**：m > min(h)；**红灯（停训归因）**：m ≤ min(h) 且 G1 绿灯（训练正常而迁移恶化 = 特化加深）。
- **记录**：每里程碑 m（含各次重复值）、训练侧对照指标、权重指纹。
- **执行环境**：Isaac 侧 GPU。

### G4 扰动稳健性

- **目的**：检测策略对单一物理参数的过拟合。
- **基准**：D 行为基线——基准变体自身（各扰动变体与无扰动基准同引擎对比）。
- **方法**：由基准环境生成 ≥5 个评测变体：接触刚度 ×2、摩擦系数 −20%、摩擦系数 +20%、整机质量 +10%、动作延迟 2 控制步（各仅改一项）；同一 checkpoint 在基准与每个变体各跑 ≥10 回合（初始状态同分布）。
- **指标**：保持率 = 变体存活 IQM ÷ 基准变体存活 IQM。
- **绿灯**：全部保持率 ≥ 0.5；**红灯**：任一变体 < 0.2。
- **记录**：变体清单（参数改动值）、逐变体保持率表。

### G5 机制监控

- **目的**：确认策略"学得健康"——不依赖蛮力、深穿透或高频抖动。
- **基准**：B 物理定律（穿透，同 V3 理论零穿透）+ D 自身趋势（力矩饱和与平滑度对照训练初期值）。
- **方法与指标**：
  - 穿透分布：同 V3，通过线同 V3；
  - 力矩饱和占比：|τ| ≥ 95% 执行器极限的控制步比例，通过线 <10%；
  - 动作平滑度：相邻控制步动作向量差的 L2 范数（窗口 500 步滑动均值），通过线为相对训练首门禁值无单调恶化（线性拟合斜率 ≤ 0）。
- **记录**：三项指标时间序列（逐门禁采样）。

## 5. 最终策略验收（Validation）

### 5.1 统计纪律

按总则 R4 执行；多动作策略须给出**性能剖面**（逐动作存活分布并列呈现），禁止以跨动作平均分掩盖单项失败。

### 5.2 测试项

| # | 测试 | 基准 | 方法 | 指标与通过线 |
|---|---|---|---|---|
| T1 | 任务质量 | D 参考动作速度与回合上限 | 诚实模式（语义同 R3）滚动，≥20 回合/动作 | 存活 IQM ≥ 80% 回合上限；速度贴合率 ∈ [0.8, 1.2] |
| T2 | 泛化 | D 训练集自身 | ≥5 条留出动作各 ≥10 回合 | 留出集 IQM ÷ 训练集 IQM ≥ 0.6 |
| T3 | 跨引擎普适 | **C 参照引擎** + D 锚点 b 与历史最优 | 参照引擎 ≥5 次重复 | 中位数 m > b 且 > 历史已训最优 |
| T4 | 机制健康 | B 物理定律 + D 自身趋势 | 同 G5 | 同 G5 |
| T5 | 扰动稳健 | D 基准变体自身 | 同 G4 | 同 G4 |

### 5.3 判定矩阵（验收通过 = T1 ∧ T3 同时成立）

| T1 | T3 | 判定与处置 |
|---|---|---|
| ✅ | ✅ | **验收通过** |
| ✅ | ❌ | **有条件通过**：技能为真、跨环境残差未破 → 执行 V6 归因差异源，评估域随机化加强或更换物理后端 |
| ❌ | ✅ | **评测异常**：优先审计评测管线语义（R3），此形态历史上多为评测错误 |
| ❌ | ❌ | **不通过**：回第 3 节重验环境 |
